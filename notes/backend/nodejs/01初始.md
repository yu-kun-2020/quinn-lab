## Node.js到底是什么？
> Node.js® is a free, open-source, cross-platform JavaScript runtime environment that lets developers create servers, web apps, command line tools and scripts.

通俗：一个软件，可以运行JavaScript代码

作用：创建服务器应用（后台接口）、创建网页应用、创建命令行工具等

特性：免费、开源、跨平台

本质：JavaScript运行时环境

## Node.js和浏览器有什么不同？
Node.js和浏览器都是JavaScript运行时环境

| 能力         | 浏览器JS | Node.js |
| ---------- | ----- | ------- |
| 执行JS       | ✅     | ✅       |
| V8引擎       | ✅     | ✅       |
| 操作网页DOM    | ✅     | ❌       |
| window对象   | ✅     | ❌       |
| document对象 | ✅     | ❌       |
| 读取服务器文件    | ❌     | ✅       |
| 创建服务器      | ❌     | ✅       |
| 访问数据库      | ❌     | ✅       |
| 操作系统       | 有限    | ✅       |
