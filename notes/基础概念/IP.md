# IP（IPv4）

## IP是什么？

本身就是一个数字标识 192.168.1.3 它是一个32bit的二进制数字，这种形式不利于记忆和阅读，所以就换了一种形式去展示，IP是用来标识网络中的设备，实现设备之间的通信。

## 什么都系有IP

只要接入互联网，都会有一个IP地址，手表、手机、平板、摄像头.....

## IP地址的数量

2的32次方差不多是40亿，但是全球人口早已超出40亿，而且一个人可能会有多个设备，所以IP地址是不够用了。

解决方法：区域共享IP （局域网IP）

## 国内的运营商

中国移动、电信、联通

广域网IP（外部网络进行通信）

## 一个特殊的 IPv4 地址 127.0.0.1

127.0.0.1指向本机Loopback，帮助你自己找到自己（回环地址）

127.0.0.0 ～ 127.255.255.255 都是回环地址

## 总结

| 类型              | 完整地址范围                       | 含义       |
| ----------------- | ---------------------------------- | ---------- |
| **IPv4 回环地址** | `127.0.0.0 ～ 127.255.255.255`     | 本机自己   |
| **私有 IPv4**     | `10.0.0.0 ～ 10.255.255.255`       | 私有网络   |
| **私有 IPv4**     | `172.16.0.0 ～ 172.31.255.255`     | 私有网络   |
| **私有 IPv4**     | `192.168.0.0 ～ 192.168.255.255`   | 私有网络   |
| **公网 IPv4**     | 除特殊用途地址之外的公网可路由地址 | 互联网通信 |
