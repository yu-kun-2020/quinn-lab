# 防盗链

## 最常见的应用

网络上有些图片的地址，复制以后在自己的项目里，可以直接预览；有些就不行，不行的那些就是使用了防盗链。

## 什么是防盗链？

防止别人（其他网站/应用）直接引用你服务器上的资源（图片、视频、音频、文件等），从而消耗你的带宽、流量和存储，绕过你的页面、广告或登录体系

## 常用的Node.js的防盗链写法

通过中间件判断referer请求头是否是目标的地址

(express)
```js
const express = require('express')
const app = express()

// 正常页面：从自己站点加载图片
app.get('/', (req, res) => {
  res.send('<h1>正常页面</h1><img src="/img" />')
})

// 受保护资源
app.get('/img', (req, res) => {
  const referer = req.get('referer') || ''

  // 只允许自己站点引用
  if (!referer.startsWith('http://localhost:3000')) {
    return res.status(403).send('403 盗链被拦截')
  }

  res.type('svg').send(`
    <svg xmlns="http://www.w3.org/2000/svg" width="200" height="80">
      <rect width="200" height="80" fill="green"/>
      <text x="100" y="45" fill="white" text-anchor="middle">OK</text>
    </svg>
  `)
})

app.listen(3000, () => {
  console.log('http://localhost:3000')
})
```
