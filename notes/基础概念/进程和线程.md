# 进程和线程

## 进程 Process

一个正在进行中的程序

程序的一次执行过程

进程负责“装东西”

![进程](/public/images/任务管理器.png)

PID就是Process ID 进程编号

进程负责提供运行环境

不同进程之间，内存通常是相互隔离的；同一个进程里的线程，可以共享这个进程的内存。所以线程之间通信通常比较方便，但也因此容易出现数据竞争、锁、死锁等问题。

## 线程 Thread

![线程](/public/images/node线程.png)

TID就是Thread ID 线程编号

线程是程序里面执行任务的路线

一个线程属于某个进程（在进程中真正干活的人）

线程是 CPU 真正执行任务的基本单位

线程负责“干活”

线程负责执行任务

## 比喻

假设你打开了 Chrome。

Chrome 本身是一个程序
当你启动 Chrome 后，操作系统会给它分配一块独立的运行空间，这就是进程
Chrome 里面需要同时做很多事情，比如：
- 加载网页
- 执行 JavaScript
- 渲染页面
- 播放视频
- 处理鼠标键盘

这些具体的工作，可以由不同的线程来完成。
