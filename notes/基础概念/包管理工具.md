# 包管理工具

## 什么是包管理工具

包管理器就是帮你自动完成“找包、下载包、装包、管包”这件事的工具

```text
                    package manager
                          │
        ┌─────────────────┼──────────────────┐
        ↓                 ↓                  ↓
     找包/下载          版本管理           依赖关系
        │                 │                  │
        ↓                 ↓                  ↓
     Registry        semver            dependency tree
        │                 │                  │
        └─────────────────┼──────────────────┘
                          ↓
                    node_modules
```

## 什么是包（Package）

别人写好、发布出来、供你直接引用的代码模块

## 为什么需要？

核心原因是现代软件开发高度依赖第三方代码

## 最常用的包管理工具

npm(Node Package Manager)是Node.js内置的官方的包管理工具，npm 是 JavaScript / Node.js 生态的包管理器，它只管 JS 的包。其他编程语言有其他的包管理器，比如Python常用是pip，Java常用的是Maven。

## 性能更好的包管理工具

pnpm(Performant Node Package Manager)是独立的社区项目，它的设计理念是：尽量避免不同项目重复存储完全相同的依赖。

```text
传统：

项目A ──→ lodash
项目B ──→ lodash
项目C ──→ lodash

实际存储：
lodash × 3


pnpm：

项目A ─┐
项目B ─┼──→ 全局内容存储
项目C ─┘       │
                ↓
             lodash
```
