# 计算机存储容量单位

## 最小的bit
全称：binary digit
简写：b
中文名：比特/位
含义：一个二进制位，只能是1或者是0
计算机的底层所有信息（文字、图片、视频、程序）都是一连串的0和1组成的


## Byte
联想：ByteDance，字节跳动
换算：1Byte = 8bits
简写：B

### 字符编码规则
#### ASCII(American Standard Code for Information Interchange)
最初设计用一个字节表示一个字符，英文字母、数字和常见的符号，一共128个字符，最初设计的用7个bit（二进制位）进行编码 二的七次方。

#### Unicode
ASCII不够用，于是又有人发明了Unicode，因为世界上还有很多符号文字，比如中文、韩文等，Unicode的目标：给世界上每一个字符一个唯一编号。

#### Unicode 和 UTF-8编码 的关系
Unicode像一个字典，比如`中 → U+4E2D`，不利于计算机存储，于是就有人发明了UTF-8编码，这个编号怎么存成二进制。

```text
中

Unicode:
U+4E2D

UTF-8编码:
E4 B8 AD
```
所以一个中文字符，它是3bytes。UTF-8中每个字节用十六进制表示。英文字母是1byte，欧洲部分文字是2bytes，emoji是4bytes。

```text
字符
 ↓
Unicode编号
 ↓
UTF-8编码
 ↓
byte
 ↓
磁盘/网络
```
