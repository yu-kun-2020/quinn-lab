# GET和POST请求的区别

:::tip
GET 获取数据 - “后端，给我数据”
POST 提交数据/执行操作 - “后端，我给你数据，你帮我处理”
:::

## 最直观的不同 请求参数的位置不同

### GET请求会放在URL的查询参数里面

`GET /api/user?id=123`

### POST请求会放在请求体里面

`POST /api/login`

```js
{
  "username": "quinn",
  "password": "123456"
}
```

## 对比

|            | GET     | POST          |
| ---------- | ------- | ------------- |
| 主要用途       | 获取数据    | 提交数据/执行操作     |
| 参数常见位置     | URL     | Body          |
| URL是否体现参数  | 是       | 通常不是          |
| 是否适合大量数据   | ❌       | ✅             |
| 是否适合上传文件   | ❌       | ✅             |
| 浏览器刷新/重复请求 | 通常比较安全  | 可能重复产生操作      |
| 常见场景       | 查询列表、详情 | 登录、创建、上传、提交表单 |
