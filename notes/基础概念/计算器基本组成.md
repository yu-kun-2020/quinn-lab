# 计算机基本组成

## 从输入到输出

输入设备：鼠标、键盘、麦克风、摄像机
处理系统：CPU
存储设备：内存、硬盘
显示设备（输出设备）：显示器、音响

## 硬件部件
![基本组成](/public/images/计算机基本组成.png)

### CPU（大脑）
执行指令、进行计算

### 内存RAM
临时存放正在使用的数据

### 硬盘SSD/HDD（仓库）
长期保存数据

### 主板（骨架/道路）
有很多插槽，把各种硬件连接起来

### 显卡
显卡里面最重要的就是GPU图像处理器，显卡 = GPU + 显存 + 供电 + PCB电路板 + 散热系统 + 各种接口
显卡的作用，图形计算，比如游戏画面、网页渲染、视频...，现在AI 训练、深度学习、CUDA 等大量使用 GPU

![机箱](/public/images/机箱.png)

### 散热器
CPU、GPU在工作的时候会产生大量的热量，如果不及时散出，会影响计算效率，常见的散热器类型有风扇、水扇

### 总线BUS
各种部件之间，通过总线、控制器、接口、协议进行通信

### 外部设备

显示器、键盘等
